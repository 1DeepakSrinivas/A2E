# Documents

Read them in this order:

1. [USER_GUIDE.md](USER_GUIDE.md) explains how to set up a machine, run suites, stop and resume them, and read the results.
2. [CONFIG_REFERENCE.md](CONFIG_REFERENCE.md) lists every field of the suite files, the model registry, the machine settings and the test groups.
3. [DATA_DICTIONARY.md](DATA_DICTIONARY.md) lists every table and column of the results database, and the formula for every derived number.
4. [ARCHITECTURE.md](ARCHITECTURE.md) describes the modules, the data flow, the job lifecycle and how to extend the system.
5. [REPORT.md](REPORT.md) is the methods report. It is organized by functional and non-functional areas and records every design decision.
6. [PREREGISTRATION.md](PREREGISTRATION.md) states the research question, measures and hypotheses for the success-per-joule study, written before the full sweep.

[../REFERENCES.md](../REFERENCES.md) lists every external source the project uses.
